# FanPitch — 3-minute video script

> **Constraints (hard from the brief):**
> - **Max 3 minutes** (3:00 is the absolute cap — judges stop watching).
> - **Max 720p** (1280×720). QuickTime / OBS / Loom — all default to ≤720p.
> - **Format**: mp4. Audio must be clean (lavalier or close mic).
> - **Focus**: a *demo* or *KPI explanation*. We go demo.
> - **Judging**: 34 % Technical Innovation · 33 % Implementation · 33 % Market.
>
> **Setup before recording (15 minutes):**
> 1. Backend up: `bash scripts/run.sh prod` shows `ec2-63-184-221-33...` healthy.
> 2. Run the simulator on EC2: `python manage.py run_simulator --match-id 1 --speed 10` (kicks off auto-events + bot reactions).
> 3. Device A (your iPhone) logged in as `congo_general / fanpitch2026`.
> 4. Device B (a second phone OR an emulator) logged in as `lisbon_lion / fanpitch2026`.
> 5. Both devices on tab "Pour toi" (For You) to start.
> 6. OBS / QuickTime / Loom recording at 1280×720, 30 fps, single take.

## Quick wins / pitfalls

✅ **Do**
- Single take if possible — re-record only if it's a hard fail.
- Lavalier mic or AirPods Pro for clean audio.
- Screen record at exactly 1280×720 — don't downscale 4K (you'll waste bitrate on artifacts).
- Speak slowly. 3 min feels long when speaking, short when watching.

❌ **Don't**
- Show the IDE, terminal, or any code (judges care about the experience, not your stack).
- Linger on transitions — every cut should advance the story.
- Promise features you haven't built — they verify against the repo.

## Tools that will work

- **macOS QuickTime** → File > New Movie Recording → mirror iPhone via Lightning, record at 720p.
- **OBS Studio** → set canvas 1280×720, capture iPhone display via USB capture device.
- **Loom Desktop** → already records ≤720p by default; export as mp4.
- **iPhone Screen Recording** + iMovie to cut → export 720p.

## Backup plan if simulator fails on stage

The featured ARG vs FRA card uses a fixed YouTube video — it will *always* play even if the backend simulator hiccups. Open that card first if anything feels off.
